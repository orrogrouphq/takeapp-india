# TakeApp India

[Visit TakeApp](https://takeapp.in/) · [Open the web app](https://app.takeapp.in/)

TakeApp provides billing and point-of-sale tools for Indian small businesses on web and Android. This repository contains public product information. TakeApp is proprietary subscription software.

## Main features

- Create itemised invoices and print or share bill PDFs.
- Use Quick POS for counter sales.
- Manage products, stock and customer records.
- Record supplier purchases and operating expenses.
- Review sales transactions and business reports.
- Choose a storefront design, preview a catalogue and share a store link.
